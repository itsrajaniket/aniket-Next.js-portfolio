# Resume Folder

Place your resume file here and name it **`resume.pdf`**.

The portfolio is configured to serve this file as your official resume. When a user clicks "Download Resume", they will receive this file renamed as **`Aniket_Raj_AI_MERN_Full_Stack.pdf`**.

## Why this structure?
- **Stability**: You don't need to change any code when updating your resume. Just replace the `resume.pdf` file.
- **SEO & Professionalism**: The downloaded filename is standardized regardless of your internal file naming.
